КАРТА ЗАГРОЗ — Харківська, Дніпропетровська, Запорізька області
===============================================================

ЯК ЗАПУСТИТИ (рекомендовано)
----------------------------
Подвійний клік по файлу run.cmd — карта відкриється в браузері на
адресі http://127.0.0.1:8802/index.html.
Цей спосіб використовує локальний сервер (server.ps1) — він сам
читає Telegram і офіційні API, тому все працює найстабільніше.
Вікно cmd можна закрити — сервер працює у фоні.

(Можна і просто відкрити index.html — тоді карта спробує читати
дані через публічні проксі, це менш надійно.)

ЩО НА КАРТІ
-----------
- Області закрашені (без шариків):
  🔴 червона = повітряна тривога зараз (офіційно або по каналах)
  🟡 жовта = загроза: в каналах репортять шахеди/КАБи/ракети,
     але офіційної тривоги ще немає
  🟢 темна = чисто, тривоги немає
- ТРЕКІНГ ДРОНІВ наживо:
  🛸 точка = де зараз летить дрон/шахед (позиція з поста:
     "над Славгородом", "Солоне 2000м" тощо)
  🎯 / 💥 / 🚀 точка = МОЖЛИВА ЦІЛЬ (куди курс: "курсом на Солоне",
     "в напрямку Софіївки" тощо)
  помаранчева пунктирна лінія = напрямок польоту
     від позиції 🛸 до цілі 🎯
  Клік на точку — пост, час і канал-джерело.
- СПРАВЖНІ КАРТИ (перемикач справа зверху на карті):
  🗺 Схема (темна) і 🛰 Супутник (реальні знімки Esri)
- ТОЧНІ КООРДИНАТИ:
  📍 у нижньому правому куті — координати під курсором мишi
  📍 в кожній точці загрози (клік на 🛸/🎯) — точні координати місця
- Лічильники зверху зліва: 🔴 скільки зон у тривозі, і по типах:
  🛸 скільки каналів репортять шахеди, 💥 КАБи, 🚀 ракети...
- Панель "Офіційно": статус тривог по 3 областях з офіційних
  джерел (alerts.com.ua → ubilling.net.ua → офіційні TG-канали)

   TG povitryana_tryvoha

ОФІЦІЙНЕ API alerts.in.ua (найнадійніше джерело)
-------------------------------------------------
1) Безкоштовний токен: https://alerts.in.ua/api-request
2) Створи файл alerts_token.txt поруч з server.ps1, встав у нього
   тільки токен (один рядок).
3) Перезапусти run.cmd. Карта візьме тривоги з офіційного API;
   якщо токена немає або API недоступне — працюють запасні джерела.

ОФІЦІЙНІ ТРИВОГИ / СИРЕНА
-------------------------
Справжнє підключення до офіційних даних (3 джерела по черзі):
1) alerts.com.ua  2) ubilling.net.ua  3) TG-канали air_raid_alert_ua
На карті і в панелі видно статус СИРЕНИ по кожній області:
🔔 Сирена: Дніп.:🔴 · Харк.:🟢 · Запо.:🟢 — плюс час оновлення.
Коли офіційно сирену УВІМКНУЛИ:
  - область фарбується в червоний
  - банер "СИРЕНА УВІМКНЕНА" на екрані
  - звук реальної сирени (4 цикли підйом-спад), якщо 🔊 Звук увімкнено
Коли ВІДБІЙ: банер "ВІДБІЙ" + мʼякий сигнал.
Кнопка "🔊 Звук" — увімкнути/вимкнути звукові сигнали.
Оновлення офіційних даних — кожні 45 сек.

ОНОВЛЕННЯ І СВІЖІСТЬ
--------------------
Кожен канал оновлюється кожні 20 сек (по черзі, зсув 3с),
офіційні дані — щові 45 сек. Кнопка "⟳ Оновити" — миттєво.
Кнопка "🔊 Звук" — сигнал при новій тривозі.
ВАЖЛИВО: якщо в каналі немає нових постів понад 1 хвилину —
точки загрози зникають, а тривога знімається (дані вважаються
застарілими). У списку каналів видно "⏳ немає новин понад
хвилину — тривога знята".

ФАЙЛИ
-----
run.cmd     — запуск (подвійний клік)
server.ps1  — локальний сервер+проксі (запускається run.cmd)
              адреса карти: http://127.0.0.1:8802/index.html
index.html  — вся карта: код, канали, місця, ключові слова
README.txt  — ця інструкція

ЯК ДОДАТИ КАНАЛ / МІСЦЕ
-----------------------
index.html у Блокноті:
1) CHANNELS — скопіюй блок, зміни id (з посилання), name, zone,
   center [широта, довгота], oblast: "dnipro" | "kharkiv" | "zaporizhzhia"
2) PLACES — нові місця для цілей 🎯
3) RE_ALERT / RE_CLEAR — ключові слова тривоги/відбою

ОБМЕЖЕННЯ
---------
- Приватні канали (t.me/+...) читати не можна — тільки через бота.
- Це неофіційна карта: стан по словах у постах, можливі хибні
  спрацювання. Офіційно — сирена та alert.in.ua.
